## С чего продолжить

Полное ревью с расположением кода, причинами и случаями для регрессий сохранено в [отчёте](reviews/2026-11-10-stage-a-review.md).

Исправления ещё не начаты:

1. **P1:** локальные/глобальные координаты панели на внешнем дисплее смешаны; использовать действительно выбранный по UUID дисплей, а не ошибочно определённый `panel.screen`.
2. **P2:** распознаваемый, но обрезанный PNG проходит поверхностную проверку `NSImage`; не заменять хорошее фото повреждёнными данными. Нужна регрессия с валидным заголовком и неполными пикселями.
3. **P2:** Shift, зажатый до начала перетаскивания выбранного слоя, снимает выделение. Различать Shift-клик и Shift-перетаскивание.
4. **P2:** автосохранённый текст не передаётся потребителю сцены до окончания редактирования; блокировка во время ввода может показать старый текст.
5. **P2:** первый введённый и затем полностью удалённый новый текст может сохранить пустую сцену и отключить прежний отсчёт, хотя вставка отменена. Отличать предварительный ввод от намеренно сохранённой пустой сцены.
6. **P2:** неизменная статичная сцена перерисовывается каждую секунду из-за тика прежнего отсчёта. Сохранить опрос состояния и обновление таймера, не инвалидируя неизменную сцену.

Следующий шаг по плану — одна общая подзадача исправлений по всем шести замечаниям, целевые регрессии, сборка и одно повторное ревью исправлений. После этого обновить хеш/результаты проверки, если исполняемый файл изменился. Никаких исправляющих подзадач к моменту паузы не запущено.

Отдельно остаются ручные проверки внешней картинки из общего буфера, drop файла из Finder, физического переподключения дисплеев, восьмисекундной панели и настоящей блокировки. Результаты старого отсчёта не подтверждают новую сцену на защищённом экране. Заметки, таймеры/пресеты и мышиные ручки ресайза/обрезки/вращения относятся к следующим этапам.
