# Проверка новых функций редактора — 13 ноября 2026

## Реализация

Ветка: `codex/editor-refinements`, база `da2cb53` из `origin/main`. Реализованы:

- Приблизительные системные ориентиры подогнаны под пользовательское наложение 1512 × 982 pt: часы смещены вниз, добавлены дата и имя, уточнена геометрия аватара и области входа. Пользовательские элементы не менялись. Совпадение с настоящим защищённым экраном требует нового визуального подтверждения пользователя.
- Option + resize пропорционально масштабирует от центра, включая края, группы и повёрнутые элементы. Crop с Cmd имеет приоритет; Option-перемещение по-прежнему копирует. Заметки сохраняют кегль, текст/таймеры/часы масштабируют отображение.
- Открытые редакторы переводят приложение в regular activation policy (Dock/Cmd+Tab). Закрытие последнего редактора сохраняет процесс и статус-меню, переводя в accessory. Временное скрытие во время проверки панели не считается закрытием.
- «Добавить» → «Часы»: системный или явный пояс, секунды, 12/24 часа, общая типографика. Редактор и панель используют общий presenter и существующий секундный источник. Неизменное значение не перерисовывается; тики не меняют документ, сохранение или Undo.
- Постоянные вложенные группы: Cmd+G / Cmd+Shift+G, дерево в списке слоёв, выбор дочернего слоя двойным кликом или его строкой. Группы переименовываются без изменения имён слоёв. Копирование ремапит всю иерархию. Формат старых документов поддержан необязательными полями.
- Шесть команд выравнивания по общему габариту выделения; группа перемещается как единое целое. Числовой размер группы применяет единое пропорциональное преобразование с опорой на левый верхний угол.

Прямое скрытие системных часов не реализовано: подтверждённого публичного API не найдено. Кнопка в инспекторе открывает нужный системный раздел. На macOS 15.7.3 проверено, что там есть `Show large clock`; прежнее значение `On Lock Screen` не менялось. Этот переход и инструкция не равнозначны автоматическому переключателю.
