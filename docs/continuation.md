## Скругление: принято пользователем

Нативная continuous-форма Apple используется общей отрисовкой и маской нативного ввода. Общее поле радиуса доступно всем типам; один круглый маркер внутри выделения меняет радиус без конфликта с ресайзом/вращением. Предел — половина меньшей стороны каждого листа, 0 — прямые углы. Clamp сохраняется при фактическом resize/crop и нативном изменении ширины. Preview не сохраняет сцену, один жест — один Undo, Escape отменяет.

Один scoped reviewer обнаружил пропущенный clamp нативной ширины; исправлено. Нативный smoke дополнительно выявил неверное отображение введённого сверх предела числа; поле теперь нормализуется при завершении ввода. Адресные проверки, финальные семь наборов тестов, universal build, подпись, diagnose и нативный smoke прошли. Проверки повторялись только после выявленных ошибок/исправлений. Подробности: [проверка скругления](native-smooth-corners-verification.md), [план](superpowers/plans/2026-11-13-smooth-corners.md).
