## Готово

Предыдущие этапы: произвольные текст/фото/заметки/таймеры, слои, импорт/замена, инспектор, сохранение, Undo/Redo, ресайз/вращение/Cmd-обрезка и устойчивость панели. Семь наборов тестов и нативные проверки приняты; основная настоящая блокировка подтверждена пользователем («проверил, все работает»), сон — предварительно («вроде работает»).

Новый этап реализован:

- Уточнены приблизительные ориентиры системных часов и входа по скриншоту; геометрия пользовательских элементов не менялась.
- Option + resize пропорционально масштабирует от центра; обычное Option-перемещение копирует.
- Dock/Cmd+Tab при открытом редакторе, только верхний бар после закрытия последнего редактора; повторное открытие возвращает окно.
- «Добавить» → «Часы»: текущие часы/минуты, секунды, 12/24 часа, системный или явный пояс, типографика, общий секундный источник. Тики не сохраняют сцену и не создают Undo.
- Вложенные постоянные группы Cmd+G / Cmd+Shift+G, дочерний слой по двойному клику или строке списка, переименование, копирование с независимыми IDs, сохранение/Undo. Числовой размер группы масштабирует её целиком пропорционально.
- Шесть выравниваний по габариту выделения, группа — единый объект. Такое поведение согласовано пользователем.

Прямого переключателя системных часов нет: подтверждённый публичный API не найден. В инспекторе собственных часов есть проверенный переход к `System Settings → Lock Screen`. Системное `Show large clock` не менялось. Переключатель «Часы» вверху редактора управляет только ориентиром.

Один проверяющий обнаружил ошибку числового размера группы; она исправлена и покрыта регрессией. Все семь наборов тестов, universal build, подпись, diagnose и изолированная нативная проверка прошли. Сохранилось прежнее предупреждение NSLayoutConstraint в lock-тестах. Подробности: [проверка нового этапа](native-editor-refinements-verification.md), [план](superpowers/plans/2026-11-13-editor-refinements.md).
