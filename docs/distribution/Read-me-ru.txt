TEotW — Следующий конец света
Версия 0.4.0

Установка
1. Скопируйте TEotW.app в папку «Программы» (Applications).
2. Извлеките установочный образ, если вы открыли DMG.
3. Запустите приложение из «Программ».

Требования
macOS 15 или новее. В приложении есть обе архитектуры: Apple Silicon и Intel.
Показ на блокировке проверялся вручную на macOS 15.7.3, Apple Silicon.
На Intel и других версиях macOS показ поверх блокировки пока не проверен.

Первый запуск
Это сборка для передачи друзьям с локальной ad-hoc подписью.
Она НЕ подписана сертификатом Developer ID и НЕ нотариально заверена Apple.
При загрузке из интернета macOS может заблокировать первый запуск.
Проверьте, что получили файл непосредственно от Дмитрия и доверяете ему.
Официальное описание проверки приложений и действий при предупреждении:
https://support.apple.com/en-us/102445
Установка сама не меняет настройки безопасности macOS.

Как пользоваться
Приложение находится под иконкой черепа в строке меню, а не в Dock.
Оставьте включённым «Показывать при блокировке» и нажмите Control–Command–Q.
Системные часы можно отключить в настройках экрана блокировки, чтобы они не
конкурировали с таймером. Приложение не меняет эту настройку автоматически.

В редакторе можно менять шрифт, начертание, кегль, высоту строки,
межбуквенный интервал и выравнивание каждого блока.
Перетаскивайте блоки мышью. Shift фиксирует ось. Рамка с пустого места
выделяет группу; Shift-клик добавляет блок. Стрелки двигают выделение на
1 pt, Shift + стрелки — на 10 pt. Справа есть две кнопки центрирования.
Дополнительную информацию можно включить отдельным переключателем.
Настройки сохраняются автоматически отдельно для каждого пользователя.

В каталоге 58 карточек на 2026–2040 годы. Выбор карточки меняет только предпросмотр.
На блокировке выбирается ближайшая дата из очереди точного отсчёта.
Годы и окна показываются как текст, без выдуманной точной даты. Далёкие
сроки и миллиарды лет исключены. Из 58 карточек 19 имеют проверенный
одиночный день и допущены в очередь, включая этапы связанных сценариев. Если автор не указал час, условно используется 00:00 по Москве.
Каталог фиксирует опубликованные утверждения, а не истинность предсказаний.
Вероятное сближение астероида не означает неизбежное столкновение.

Ограничения
Используется экспериментальный приватный API macOS. Обновления системы
могут повлиять на показ поверх блокировки. Приложение не заменяет Touch ID
или пароль и не работает на загрузочном экране FileVault. После перезагрузки
его нужно запустить заново. Автозагрузки нет.
Интернет нужен только для открытия источников; сам отсчёт работает офлайн.
Журнал диагностики: ~/Library/Logs/TEotW/diagnostics.log.
Содержимое пользовательских окон, пароли и нажатия клавиш не собираются.

Удаление
Завершите приложение через меню черепа и удалите TEotW.app из «Программ».
