## Поведение

- Все пять существующих инструментов «Добавить» ждут следующего клика по холсту. После создания возвращается выделение; Escape отменяет режим и незавершённую рамку. Клик снаружи холста не создаёт объект.
- Текст начинается в точке клика либо в протянутой рамке. Заметка, таймер, часы и фото центрируются в точке; прежнее ограничение рамок заметки/таймера/часов границами холста сохраняется. У фото диалог открывается после клика; отмена диалога не создаёт слой/Undo.
- ПКМ по пустому холсту предлагает создание и «Вставить сюда». Создание из меню выполняется сразу в точке вызова. ПКМ по объекту выбирает его, а внутри текущего множества сохраняет выбор. Неприменимые команды отключены.
- Меню объектов вызывает прежние копирование, порядок слоёв, группировку/разгруппировку и новую блокировку. Нативное меню активного NSTextView сохранено.
- «Вставить сюда» поддерживает текст, изображения и приватный формат слоёв. Копии получают независимые IDs/группы, их преобразованный габарит центрируется в точке. Текст начинается в точке; фото добавляется отдельным объектом даже поверх выбранного изображения. Cmd+V и drag/drop сохраняют прежние правила. «Вставить с заменой» использует существующий импорт `.replace(id)` с сохранением рамки, ID, стиля и прежней логики crop.
- Блокировка по уточнению пользователя запрещает выбор курсором, включая рамку и расширение групп. В списке слоёв можно выбрать заблокированный объект и менять его свойства. При начале мышиного жеста locked исключаются из выделения, но числовые/клавиатурные операции над выбором из списка доступны.
- В каждой строке слоёв есть кликабельный замок. Замок группы управляет всеми потомками, смешанное состояние обозначено полупрозрачным замком. Уже выбранный через слои locked-объект может предложить «Разблокировать» в своём ПКМ без нового курсорного выбора.
- `locked` — необязательное поле, отсутствие означает false. Оно сохраняется, копируется и поддерживает Undo/Redo. Блокировка не скрывает элементы и не меняет renderer.
- Подсказка системных часов по-прежнему открывается только по нативной кнопке «?», без автопоказа.

Фигуры относятся к отдельному этапу §8. Их неработающие пункты не добавлены. Новое управление видимостью и остальные подсистемы UI также остаются отдельными этапами.
