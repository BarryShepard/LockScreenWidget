## Поведение

- Отдельные элементы и группы: без Shift оси независимы, Shift сохраняет пропорции. Option сохраняет прежнее пропорциональное изменение от центра. Cmd-обрезка фото и Shift при перемещении не менялись.
- У одиночного текста, таймера, часов и стикера все восемь маркеров меняют только рамку. Кегль, существующий масштаб отображения букв и стиль не меняются; текст перестраивается под доступную ширину. Высота рамки задаётся жестом, без автоматического подгона во время ресайза.
- При изменении ширины обычного текста отключается автоматическая ширина. Вход в нативный ввод сохраняет заданную пользователем ширину.
- У стикера вертикальный край теперь меняет только высоту, горизонтальный — только ширину. Удалено прежнее особое исключение для горизонтального края: единое правило действует для всех направлений. При Shift пропорции бокса фиксируются, шрифт остаётся прежним.
- Скругление текстовых боксов сохраняется, пока допускает новый размер, затем ограничивается половиной меньшей стороны. Фото сохраняет масштабирование содержимого. Группы по прежнему согласованию преобразуют всю композицию вместе с содержимым; этот механизм не заменён переразбивкой отдельных листов.
