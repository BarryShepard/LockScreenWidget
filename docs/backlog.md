### Ориентиры часов и входа

- По пользовательскому скриншоту с полупрозрачным наложением настоящей блокировки элементы композиции стоят точно, а ориентиры часов и входа расходятся с системой.
- Исправить положение и размер ориентиров часов, аватара/имени и поля входа. Часы на наложении находятся ниже текущего ориентира; у входа также есть расхождение геометрии.
- Сверять геометрию по системным областям; разные значения времени на скриншотах не считать ошибкой.
- Проверить на экране 1512 × 982 pt, macOS 15.7.3; независимое переключение часов и общих ориентиров сохраняется. Геометрию пользовательских элементов не менять.
- Референс: приложенный пользователем скриншот 13 ноября, `codex-clipboard-ddca6a29-293c-45aa-99c2-51cfe1ab53f6.png`. Временный файл не является постоянным ресурсом репозитория; скриншот с пользовательскими данными в Git не добавлять.

### Option: пропорциональное масштабирование от центра

- При перетаскивании рамки с Option масштабировать пропорционально относительно центра: противоположные стороны движутся одновременно, центр остаётся на месте.
- Применить к отдельному элементу и множественному выделению; согласовать с существующими Shift, Cmd-обрезкой и Option-копированием при перемещении.
- Один жест — одно Undo; отмена жеста восстанавливает исходную геометрию. Сохранить особенности заметок, текста, таймеров и обрезанных фото.

### Dock и переключатель приложений

- Пока редактор открыт, приложение видно в Dock и системном переключателе Cmd+Tab (пользователь назвал его Alt+Tab).
- Закрытие окна редактора скрывает приложение из Dock/Cmd+Tab; оно продолжает работать в верхней панели и показывать композицию при блокировке.
- Повторное открытие редактора через верхнюю панель возвращает Dock/Cmd+Tab. Закрытие окна не равно выходу; команда выхода завершает приложение.
- Проверить сохранение, активный ввод, восстановление окна и отсутствие лишних окон/потери фокуса при смене режима.

### Постоянные группы слоёв

- Cmd+G создаёт группу из выделенных слоёв; Cmd+Shift+G разгруппировывает.
- Группа сохраняется в документе и восстанавливается после запуска; отображается в списке слоёв. Выделение и преобразования группы работают как целого.
- При группировке/разгруппировке сохраняются вид композиции, порядок слоёв и ресурсы. Операции поддерживают Undo/Redo.
- Согласованы вложенные группы и выбор дочернего слоя двойным кликом. В списке слоёв группы показываются с вложенными строками, доступно переименование. Старые сцены загружаются без групп.

### Выравнивание относительно других элементов

- Для нескольких выбранных элементов добавить выравнивание по левому/правому краю, верхнему/нижнему краю, горизонтальному и вертикальному центру.
- Это отдельные команды от существующего центрирования набора на холсте. Пользователь выбрал опору по общему габариту выделения. Группа выравнивается целиком.
- Учитывать поворот и группы; одна команда — одна операция Undo. Незатронутые свойства и порядок слоёв сохраняются.

## Блок текущего времени

- Добавлен в текущий объём: «Добавить» → «Часы». Формат 24/12 часов, секунды, системный либо явный часовой пояс, общая типографика, перемещение, масштабирование и Undo/Redo.
- Использует тот же секундный источник, что и таймеры; без секунд обновляется при смене минуты, документ при тиках не сохраняется.
- Для замены системных часов добавлен переход к настройкам экрана блокировки с пояснением, как скрыть большие часы. Прямое переключение из приложения не реализовано: подтверждённого публичного API нет. Если такое управление будет добавляться, оно потребует отдельной проверки на поддерживаемых версиях macOS.

## Нативное скругление и маркер — текущий этап

- В ветке `codex/smooth-corners` реализована нативная форма Apple continuous; единый путь обрезает фото, текст, заметки, таймеры и часы. Та же форма ограничивает нативный ввод.
- Общее поле радиуса доступно всем типам и множественному выделению. Радиус ограничивается половиной меньшей стороны каждого элемента; 0 возвращает прямые углы.
- Круглый маркер внутри рамки меняет радиус всего выделения; движение внутрь увеличивает радиус. На малых рамках он скрывается, чтобы не пересекаться с ресайзом/вращением. Один жест — один Undo, Escape отменяет.
- Семь наборов тестов, universal build, подпись и нативный smoke прошли. Требуется пользовательское визуальное согласование формы. Подробности: `docs/native-smooth-corners-verification.md`.
