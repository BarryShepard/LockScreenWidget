# Публикация Mice и переименование репозитория

По запросу пользователя от 14 ноября 2026 название и описание на GitHub обновляются вместе со следующей отправкой изменений. В рамках локального ребрендинга удалённый репозиторий и remotes не меняются.

- Текущее origin: `BarryShepard/LockScreenWidget`.
- Новое имя репозитория: `Mice`.
- Описание: `Mice — редактор личного экрана блокировки для macOS. Фото, текст, заметки, часы и таймеры в вашей композиции.`
- README: `Mice — личный экран блокировки для macOS`.
- Основная иконка: `Resources/Branding/AppIcon.png` (синяя фактурная мышь на кремовой основе).
- Строка меню: `StatusIcon.mouse()` (чистый монохромный силуэт).
- Курсор: обычный системный.

При следующей публикации проверить имя `BarryShepard/Mice`, переименовать только репозиторий origin и обновить его описание. Если имя занято, сообщить пользователю и не выбирать другое без согласования. После успешного переименования обновить fetch/push URL origin на `git@github.com:BarryShepard/Mice.git` и проверить README/ссылки публикации. `upstream` относится к прежнему проекту TEotW и не переименовывается автоматически.

Пакеты называются `Mice-<версия>-universal.dmg` и `.zip`, приложение — `Mice.app`, исполняемый файл — `Mice`. Старые выпуски, история проекта, bundle identifier `local.teotw.countdown`, существующие ключи настроек, `Application Support/LockScreenWidget` и `Logs/TEotW` сохраняются для совместимости.

14 ноября пользователь запросил пуш текущего состояния. Исходники отправляются в существующий `BarryShepard/LockScreenWidget`, ветка `main`. Автоматическая проверка отклонила отдельное переименование и изменение описания: запрос «пуш в Git» не был признан явным подтверждением этих внешних изменений. До отдельного подтверждения пользователя имя/описание GitHub и remotes не менять. Название приложения Mice и выбранный брендинг включаются в публикацию исходников.

В коммит включены рабочие исходники, тесты, скрипты, выбранный `Resources/Branding/AppIcon.png`, документация и референсы UI. Локальный AGENTS.md, экспериментальные иконки Resources/AppIcon, личные сцены и build-артефакты не публикуются.
