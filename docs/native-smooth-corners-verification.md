# Нативное скругление — 13 ноября 2026

## Результат

Ветка `codex/smooth-corners`, база `0f6962e`. База отправлена в `origin/main` по запросу пользователя перед началом этого этапа. Реализованная форма готова к пользовательскому визуальному согласованию; приёмка над настоящим защищённым экраном не заявляется.

- Единый `SceneCornerPath` использует нативный `RoundedRectangle` со стилем `continuous`, а не полигональную аппроксимацию. [API Apple](https://developer.apple.com/documentation/swiftui/roundedrectangle).
- Фото, фон заметок, текст, таймеры и часы обрезаются одной формой. Подложка для прозрачных типов не добавляется. Нативный текстовый контейнер получает тот же путь с обратным преобразованием текстового масштаба; маска ограничивает и дочерние элементы ввода.
- Радиус доступен в общем поле инспектора для всех типов и множественного выделения. Дублирующее поле таймера удалено. 0 даёт прямые углы; ввод ограничивается половиной меньшей стороны каждого листа. Смешанные значения показывают «Разные».
- Старые документы с большим сохранённым радиусом загружаются без перезаписи; отображается эффективный ограниченный радиус. При фактическом ресайзе/обрезке, включая нативный жест ширины, новое ограничение сохраняется в документе.
- Круглый маркер располагается внутри рамки верхнего выбранного листа. Он работает на повёрнутых элементах и задаёт общий радиус выделению; малые элементы ограничиваются своим пределом. Для слишком маленьких экранных рамок маркер скрыт, числовое поле доступно. Проверяется непересечение с зонами ресайза/вращения.
- Жест использует начальный snapshot, не создаёт сохранений/Undo в preview, коммитится одним действием; Escape возвращает исходное состояние.
- После завершения ввода поле получает фактически применённое значение, включая clamp и сброс некорректного ввода. Активные черновики при обычном render не заменяются.
