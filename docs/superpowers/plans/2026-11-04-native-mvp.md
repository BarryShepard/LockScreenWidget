# Native lock screen MVP Implementation Plan

> **For agentic workers:** Execute inline in this chat. No delegation is needed for this small first version.

**Goal:** Проверить настоящий живой отсчёт на заблокированном Mac, без графики и категорий.

**Architecture:** Небольшое AppKit-приложение с окном предпросмотра и отдельной прозрачной панелью для блокировки. Локальный каталог пяти будущих дат, без сетевых запросов во время работы. Панель не принимает фокус и пропускает мышь; её видимость ограничена состоянием блокировки.

**Tech Stack:** Swift, AppKit, CoreText, CoreGraphics, swiftc; macOS 15+.

## Global Constraints

- Центрирование, суммарные часы:минуты:секунды; миллисекунд нет.
- Заголовок прописными с разрядкой 0,06 em; Manrope с кириллицей.
- Только название, отсчёт, короткое пояснение и источник в основном блоке.
- Реальный системный вход остаётся системным; приложение не рисует поле пароля.
- Без графики, подписей категорий, автозагрузки и изменения обоев.
- Время без часа в источнике: 00:00 Europe/Moscow, явно описанная условность в настройках и README.
- Не блокировать компьютер автоматически при сборке и проверках.
