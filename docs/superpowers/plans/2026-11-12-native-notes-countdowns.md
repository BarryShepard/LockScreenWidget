# Native notes and countdowns implementation plan

> **For agentic workers:** Use subagent-driven-development sequentially, with a fresh implementer per task and task-scoped review, then one final integration review. User authorized continuing the existing editor specification.

**Goal:** Deliver spec stage C: editable notes with fixed-frame text reflow and countdown layers with custom dates and the existing apocalypse preset.

**Architecture:** Extend the version1 Foundation document with optional per-kind payloads. Keep native text input/history shared, presentation values prepared by controllers, and views unaware of models. Use the existing common tick for dynamic countdown presentation in editor and lock panel; no persisted scene changes for ticks.

**Tech Stack:** Swift5/AppKit/Foundation/CoreText, macOS15+, existing shell/swiftc scripts.
