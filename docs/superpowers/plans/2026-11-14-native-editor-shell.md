# Нативное окно редактора — план реализации

> **For agentic workers:** Выполнять последовательно одним агентом в текущем checkout по AGENTS.md. Сохранить существующие локальные изменения аффинных преобразований и пользовательские сцены.

**Goal:** Реализовать законченный первый этап новой спецификации: сворачиваемые слои, команды истории только через меню и клавиатуру, отсутствие входа в прежний редактор и независимые ориентиры с уведомлением о настройках macOS.

**Architecture:** Состояние раскрытия слоёв и ориентиров хранится только в нативных views/window controller; оно не входит в документ и его Undo. Существующая responder chain меню «Правка» сохраняет нативную историю активного текста. Прежняя модель отсчёта остаётся для совместимости и первого запуска.

**Tech Stack:** Swift 5, AppKit, существующие swiftc-скрипты, macOS 15+.

## Ограничения

- Основание: §1 и независимые ориентиры из спецификации `../specs/2026-11-13-native-editor-ui.md`; пользователь выбрал этот этап 14 ноября.
- Работа в существующей папке согласно сохранённой точке передачи. Без коммитов, публикации, изменения личных сцен и автоматической блокировки.
- Сохранять существующую геометрию, ввод, сохранение, Dock/Cmd+Tab, таймеры и общую прозрачность.
- Остальные подсистемы спецификации реализуются отдельными этапами: размещение/контекстные меню; фон; типографика; стикеры; фигуры. Открытые продуктовые вопросы не решаются молча в этом этапе.
