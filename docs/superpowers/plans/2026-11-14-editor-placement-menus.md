# Размещение и контекстные меню редактора

> **For agentic workers:** Выполнять inline одним агентом по AGENTS.md; один scoped reviewer после завершения. Работать в текущей папке, сохранять параллельные изменения брендинга Mice и все прежние сцены.

**Goal:** Инструменты размещают существующие пять типов по клику; ПКМ создаёт сразу в своей точке, вставляет туда содержимое или заменяет выбранное фото. Замки исключают слои из выбора курсором, оставляя редактирование через список слоёв.

**Architecture:** Views строят нативное NSMenu из примитивного представления и отправляют типизированные действия. Canvas controller управляет одноразовым инструментом; window controller сохраняет существующий импорт и paste. Optional locked хранится в документе, отсутствующее значение означает false. Список слоёв показывает отдельную кнопку замка; выбор этой кнопкой не обязателен для изменения блокировки.

**Tech Stack:** Swift 5, AppKit, Foundation, существующие swiftc-скрипты; macOS 15+.

## Решения и ограничения

- Подтверждено пользователем: выбор инструмента ждёт клика; контекстное создание выполняется сразу в точке ПКМ. Escape отменяет размещение, после создания возврат к выделению.
- Рутинный выбор якоря: текст — левый верхний угол или протянутая рамка; заметка, таймер, часы, фото — центр в точке клика. Прежний clamp к границам для заметки/таймеров сохранён. Фото выбирается нативным диалогом после клика; отмена не создаёт слой.
- Уточнение блокировки пользователя: запретить выбор курсором; через слои разрешить выбор и правку параметров. Кликабельные замки в строках, включая группы. Блокировка не скрывает слой и не ограничивает числовые/клавиатурные команды выбранных через список объектов.
- Мышь не выбирает заблокированные объекты, в том числе рамкой и через расширение групп. При начале жеста мыши такие объекты исключаются из выделения. Замок группы применяется ко всем её листам; смешанная группа обозначается отдельно.
- Cmd+V, drag/drop и приватный формат копирования сохраняют прежнее поведение. «Вставить сюда» никогда не заменяет выбранное изображение. «Вставить с заменой» повторно использует существующий image import destination.
- Фигуры относятся к отдельному этапу §8 и не показываются неработающими пунктами. Нативный ввод текста сохраняет собственное контекстное меню.
- Подсказка системных часов остаётся только по кнопке «?», без автоматического открытия. Без коммитов, публикации и автоматической блокировки.
