# Нативное окно редактора — проверка 14 ноября 2026

Первый законченный этап [новой спецификации](superpowers/specs/2026-11-13-native-editor-ui.md). [План](superpowers/plans/2026-11-14-native-editor-shell.md). Рабочее дерево поверх `46eaef5`; изменения сохранены локально вместе с предыдущим этапом аффинных преобразований, без коммита и публикации.

## Реализовано

- Нативный disclosure сворачивает таблицу слоёв. Таблица, её выбор и иерархия остаются; refresh не раскрывает панель. Раскрытие не меняет документ или историю.
- Из окна убраны кнопки Undo/Redo и вход в прежний редактор отсчёта; из меню верхней панели также убран вход в него. Команды «Правка», Cmd+Z/Cmd+Shift+Z и нативная история текста сохранены. Прежние данные и fallback первого запуска не удалены.
- Ориентиры системных часов и входа независимы. После уточнения пользователя подсказка о системных часах перенесена из дополнительной строки панели в нативный NSPopover у кнопки «?». По окончательному уточнению пользователя поповер открывается только по клику на нативную кнопку помощи NSButton с bezelStyle .helpButton. Переключение ориентира его не открывает; повторный клик на «?» закрывает подсказку. Крестик и клик снаружи закрывают поповер без включения часов. Кнопка настроек использует прежний адрес Lock Screen; ошибка открытия отображается в статусе.

## Автоматические проверки

Новый `Tests/SceneEditorShellChecks.swift` проверяет реальные AppKit-контролы:

- сворачивание/раскрытие группы и выбор дочернего слоя во время скрытой таблицы;
- оба переключателя, показ/закрытие/повторный показ уведомления, target/action кнопки настроек с подменённым открытием (системные настройки тест не меняет);
- неизменность сцены и сохранённых байтов, отсутствие публикации и Undo от изменений интерфейса;
- отсутствие прежних кнопок, включая image-only варианты по accessibility label/toolTip;
- Undo/Redo через responder chain сначала холста, затем активного NSTextView.
